# Volna — SoundCloud, Spotify, Яндекс Музыка и своя волна

Десктопный плеер для Windows: библиотека из SoundCloud, Spotify и Яндекс Музыки в одном месте и «Моя волна» —
бесконечный поток рекомендаций, который учится на твоих лайках и скипах.

## Запуск

1. Нужна Windows 10/11.
2. Дважды кликни `run.bat`. Если Python нет, он сам поставит его через winget. В первый раз создаётся окружение и ставятся PySide6 и requests (пара минут).

Данные (база, настройки, кэш треков до 400 МБ) лежат в `%APPDATA%\Volna`.

## Откуда берётся музыка

| | Как подключается | Что даёт |
|---|---|---|
| **SoundCloud** | ссылка на профиль, вход не нужен | публичные лайки и плейлисты, поиск, весь звук, похожие треки для волны |
| **Spotify** | выгрузка данных аккаунта (ZIP) или ссылка на публичный плейлист | лайки, плейлисты, история прослушиваний |

Без Spotify Premium сторонние приложения не могут играть звук из Spotify, поэтому каждый трек Spotify
приложение само находит на SoundCloud (сравнивает название, артиста и длительность) и играет оттуда.
Треки, которых на SoundCloud нет или которые там только как 30-секундное превью Go+, помечаются «нет на SC».

**Выгрузка Spotify:** spotify.com → Профиль → Аккаунт → Конфиденциальность → «Скачать данные» →
«Данные аккаунта». Письмо с ZIP приходит за несколько дней. Если запросить ещё и «Расширенную историю
прослушиваний» — волна будет точнее (её тоже можно скормить приложению).

## Что есть в приложении

- **Главная**: быстрые плитки плейлистов, баннер «Моя волна», ежедневные миксы по любимым артистам и «Открытия дня», недавно игравшее, твои артисты, «Давно не слушал», настроения.
- **Медиатека** слева: «Любимые треки» и все плейлисты. Свои плейлисты создаются кнопкой «+», треки в них можно перетаскивать мышкой — и прямо из любого списка на плейлист слева.
- **Страница артиста**: популярное на SoundCloud, что есть в твоей медиатеке, похожие исполнители, сколько ты его слушал.
- **Статистика**: минуты, топ артистов и треков за неделю/месяц/всё время, по часам суток, жанры.
- **Очередь** справа: «Играть следующим», «Добавить в очередь», перетаскивание, удаление. Вкладка «Сейчас играет» — обложка и карточка артиста.
- **Меню «…»** у каждого трека: очередь, плейлисты, лайк, волна по треку, переход к артисту.

## Версия 0.4: звук, тексты, Windows

- **Свой звуковой движок** (PyAV + PortAudio): плавный переход между треками (0–12 с), без пауз между треками, выравнивание громкости, эквалайзер на 10 полос с пресетами, живой спектр для визуализации. Если движок не запустится, Volna сама переключится на стандартный плеер Qt.
- **Тексты песен** из открытой базы LRCLIB: синхронные строки в полноэкранном плеере и во вкладке «Текст» справа, клик по строке перематывает.
- **Windows**: медиаклавиши и окно управления музыкой Windows с обложкой, значок в трее (закрытие окна сворачивает туда — отключается в настройках), мини-плеер поверх всех окон, статус «Слушает» в Discord (нужен ID приложения, инструкция в настройках).
- **Итоги** месяца и года в виде историй — на странице «Статистика» и на главной.
- **Таймер сна** (значок луны в плеере): музыка плавно затихает через 15–90 минут или после текущего трека.
- **Настроение волны**: бодрое, спокойное, для учёбы — на странице «Моя волна».
- **Настройки**: звук, приложение, Discord, кэш.

## Версия 0.7: аккаунты и приложение для Android

- **Аккаунты.** При запуске — экран «Кто слушает?»: у каждого своя медиатека, лайки, волна, настройки и вход в Яндекс. Пароль по желанию (хранится как PBKDF2-хэш; он закрывает вход в приложении, но не шифрует файлы на диске). Твои старые данные перейдут в первый созданный аккаунт. Если аккаунт один и без пароля — Volna открывается сразу. Сменить, переименовать, поставить пароль или удалить аккаунт — в Настройках → «Аккаунт» или по кружку с буквой рядом с логотипом.
- **Volna для Android** (папка `mobile`). Тот же интерфейс и те же функции: SoundCloud, Яндекс Музыка со входом, ссылки Spotify, своя волна и «Моя волна» Яндекса, миксы, тексты, умные плейлисты, офлайн-режим, «Музыкальная ДНК», обмен плейлистами (коды совместимы с ПК), эквалайзер, таймер сна, управление из шторки и наушников, музыка в фоне. Аккаунты на телефоне свои, с ПК не синхронизируются. Нет только того, что имеет смысл лишь на компьютере: режима вечеринки, Discord, Last.fm, мини-плеера, импорта ZIP-выгрузки Spotify.

### Как собрать APK

Вариант 1 — у себя: запусти `build_android.bat`. В первый раз он сам поставит Node.js, Java 17 и Android SDK (~2–3 ГБ, 10–20 минут), дальше сборка занимает минуту-две. Готовый `Volna-0.7.0.apk` появится в папке проекта — отправь его на телефон и открой (Android попросит разрешить установку из этого источника).

Вариант 2 — на GitHub: положи проект в репозиторий, открой Actions → «Android APK» → Run workflow; APK будет в Artifacts.

Обновление приложения на телефоне — просто установи новый APK поверх (данные сохранятся, если собирать на том же компьютере).

## Версия 0.6: офлайн, музыкальная ДНК, вечеринка

- **Офлайн-режим**: «…» у плейлиста, «Любимых» или трека → «Скачать для офлайна». Скачанное лежит в `%APPDATA%\Volna\offline`, не чистится вместе с кэшем и собрано в разделе «Скачанное» слева. Значок Wi‑Fi сверху включает офлайн-режим: играют только скачанные треки, «Моя волна» собирается из них. В настройках можно включить автоскачивание лайков.
- **Музыкальная ДНК** (слева в меню): твой архетип слушателя, андеграунд-метр (по числу прослушиваний на SoundCloud), всеядность, верность артистам, энергия, жанры, эпохи, редкие находки. Кнопка «Скопировать мой код» — отправь другу, вставь его код и узнай процент совпадения вкусов и что послушать у него.
- **Режим вечеринки**: «Вечеринка» → «Начать». Гости сканируют QR-код телефоном (та же Wi‑Fi), ищут треки, добавляют до 3 своих и голосуют за чужие — очередь сортируется по голосам. Половина гостей может проголосовать за пропуск трека. При первом запуске Windows спросит доступ к сети — разреши для частных сетей.

## Версия 0.5: Яндекс, внешний вид, умные плейлисты

- **Яндекс Музыка**: Настройки → «Яндекс Музыка» → «Войти». Открывается окно входа Яндекса, токен хранится только у тебя в `%APPDATA%\Volna`. Подтягиваются «Мне нравится» и плейлисты, треки играют прямо из Яндекса (нужна Плюс), если не вышло — с SoundCloud. Волна может брать рекомендации и из «Моей волны» Яндекса. Лайки синхронизируются в обе стороны.
- **Внешний вид** (Настройки → «Внешний вид»): 9 тем и редактор своих цветов, фон (градиент, картинка, размытая обложка), шрифты, плотность, расположение панелей, стиль визуализатора, скорость анимаций, горячие клавиши. Тему можно экспортировать и отдать другу.
- **Last.fm**: скробблинг, «любимые» при лайке и похожие артисты для волны. Нужен свой ключ: last.fm/api/account/create → вставить API key и Shared secret в настройках → «Войти».
- **Умные плейлисты**: кнопка «+» в медиатеке → «Умный плейлист». Правила (источник, жанр, артист, лайк, сколько раз слушал, когда добавлен, длительность…) — список обновляется сам.
- **Ctrl+K** — палитра команд: поиск треков, артистов, плейлистов и команды вроде «таймер 30», «волна спокойная», «громкость 40».
- **Обмен с друзьями**: «…» у плейлиста → «Скопировать код» (вставляется в мессенджер) или «Сохранить файл .volna». Друг: «+» → «Плейлист от друга».
- **Установщик и автообновления** — см. «Друзьям».

## Моя волна

- **Профиль вкуса** — веса исполнителей и жанров/тегов из лайков, библиотеки, истории Spotify,
  дослушиваний, скипов и дизлайков (старое постепенно весит меньше).
- **Кандидаты** — похожие треки SoundCloud для твоих любимых треков + треки из библиотеки.
- **Режимы:** *Любимое* (в основном знакомое), *Микс*, *Незнакомое* (почти только новое).
- **Реакции работают сразу:** ♥ разворачивает волну к этому треку, скип в первые 30 секунд
  срезает эту ветку, ✕ убирает артиста и похожее из очереди.
- Правый клик по любому треку → **Волна по треку**. Поле под волной — волна по жанру/артисту
  (так же стартует, если библиотека пустая).

Горячие клавиши: пробел — пауза, Ctrl+→ / Ctrl+← — следующий/предыдущий, Ctrl+↑/↓ — громкость, L — лайк, Ctrl+F — поиск, Alt+← / Alt+→ — назад/вперёд, Esc — закрыть полноэкранный плеер.
Клик по обложке внизу открывает экран «Сейчас играет». Правый клик по треку — волна по треку.

## Друзьям

`build_installer.bat` собирает установщик `dist\Volna-Setup-<версия>.exe` (Inno Setup поставится сам
через winget). Его можно просто отправить: ставится без прав администратора, Python не нужен.
У каждого своя база и своя волна. (`build_exe.bat` собирает только папку `dist\Volna`.)

**Автообновления.** Заведи репозиторий на GitHub и выложи установщик в релиз с тегом версии:

```
gh release create v0.6.0 dist\Volna-Setup-0.6.0.exe --title "Volna 0.6.0" --notes "Что нового"
```

Вписать `логин/репозиторий` в Настройки → «Обновления» (у друзей тоже). Установленная Volna сама
проверяет релизы при запуске и предлагает обновиться в один клик. При запуске через `run.bat`
обновления не ставятся — просто замени файлы.

## Важно знать

- SoundCloud работает через публичный веб-ключ (как у yt-dlp). Это неофициально и против правил
  SoundCloud API: если ключ перестанет работать, приложение само возьмёт новый, но если SoundCloud
  что-то поменяет серьёзно — понадобится обновление кода. Только для личного использования.
- Ссылки на плейлисты Spotify читаются со страницы-виджета, обычно не больше ~100 треков.

```
main.py                 запуск
volna/soundcloud.py     клиент SoundCloud: ключ, поиск, похожие, лайки, скачивание HLS-потока
volna/spotify_import.py импорт выгрузки и публичных ссылок Spotify
volna/matcher.py        поиск треков Spotify на SoundCloud
volna/recommender.py    волна
volna/feed.py           миксы для главной
volna/audio.py          звуковой движок
volna/lyrics.py         тексты песен
volna/ui/desktop.py     трей, мини-плеер, медиаклавиши, Discord
volna/yandex.py         Яндекс Музыка: вход, медиатека, звук, «Моя волна»
volna/lastfm.py         Last.fm: скробблинг, похожие артисты
volna/smart.py          умные плейлисты
volna/share.py          коды и файлы плейлистов для друзей
volna/updater.py        обновления через GitHub Releases
volna/offline.py        скачивание для офлайна
volna/dna.py            «Музыкальная ДНК» и сравнение с другом
volna/accounts.py       аккаунты (users/<id>/ в папке Volna)
volna/ui/login_window.py экран «Кто слушает?»
volna/party.py          сервер режима вечеринки (страница для телефонов — volna/web/party.html)
installer.iss           сценарий установщика (Inno Setup)
mobile/                 приложение для Android (Capacitor): src/engine — движок на JS, src/mobile.* — оболочка,
                        общий интерфейс берётся из volna/web при сборке (scripts/prepare.mjs)
build_android.bat       сборка APK
volna/library.py        импорт профиля/ссылок SoundCloud
volna/db.py             SQLite
volna/ui/               окно, плеер, мост Python ↔ интерфейс
volna/web/              интерфейс (HTML/CSS/JS, шрифты Unbounded и Manrope, иконки Lucide)
volna/assets/           иконка приложения
```
